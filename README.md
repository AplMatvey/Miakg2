# Лабораторная работа №2 — вариант 4

Для обычного запуска дважды щёлкните по файлу `Запустить_лабу.bat` в папке
проекта.

В Visual Studio Code выберите конфигурацию `Запустить лабораторную` рядом с
кнопкой запуска. После этого лабораторная запускается кнопкой с треугольником
или клавишей `F5`.

Программа рисует последовательность вложенных четырёхугольников. Каждая
новая вершина вычисляется по формуле из задания:

```text
x' = (1 - mu) * x[i] + mu * x[i + 1]
y' = (1 - mu) * y[i] + mu * y[i + 1]
```

Коэффициент `mu` вычисляется для варианта `k = 4`, поэтому узор получается
упорядоченным. Все стороны рисуются собственным алгоритмом Брезенхейма, а
перенос, поворот и масштабирование выполняются общей матрицей аффинного
преобразования.

## Управление

- `W`, `A`, `S`, `D` или стрелки — перемещение;
- `Q`, `E` — поворот;
- `+`, `-` — изменение масштаба всего координатного поля;
- левый щелчок мыши — поставить отдельную точку вращения;
- правая кнопка мыши + движение — перемещение;
- колёсико мыши — изменение масштаба всего координатного поля;
- `N`, `M` — увеличить или уменьшить число вложенных фигур;
- `[`, `]` — изменить число вершин (от 3 до 12);
- `R` — вернуть начальное состояние;
- `Esc` — выйти.

Красная отметка показывает выбранную точку. Клавиши `Q` и `E` вращают всю
фигуру вокруг неё.

## Сборка

Требуются CMake 3.11+, компилятор C++ и доступ в интернет при первой сборке:

```powershell
cmake -S . -B build
cmake --build build --config Debug
```

После сборки запустите `build/Debug/sdl2-demo.exe` (Visual Studio). В Visual
Studio Code также можно открыть папку проекта и нажать `F5`.

Основная часть решения находится в `src/draw.cpp`: `line_bresenham` рисует
отрезок, `draw` строит узор, а `handle_key` реализует управление.
